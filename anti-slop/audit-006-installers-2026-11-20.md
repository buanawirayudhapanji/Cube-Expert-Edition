# Audit sebelum packaging Linux dan Windows

Permintaan pengguna: paket Linux dan Windows, tanpa instalasi Python manual. Audit menemukan belum ada metadata dependency/build/installer; aplikasi memakai PySide6, QtMultimedia, mido dan python-rtmidi serta aset relatif `suite_gui.ASSETS`. `midi.enumerate_ports` memaksa LINUX_ALSA; Windows memerlukan WINDOWS_MM. Koleksi dan cadangan default berada di sebelah source, yang tidak cocok untuk AppImage read-only atau lokasi instalasi.

Rencana bertahap: (1) tambah helper lokasi data; mode source tetap memakai folder proyek dan env Koleksi yang sudah ada, mode frozen memakai lokasi data per pengguna. Ganti hanya lokasi default pada Collection, BackupPanel, GUI, suite dan BankTransfer; format dan logika transfer tidak berubah. Pilih API MIDI berdasarkan OS tanpa mengubah protokol/pesan. (2) build PyInstaller onedir dengan semua aset, modul MIDI dinamis dan QtMultimedia/native dialog plugin; AppImage Linux plus integrasi menu per pengguna, Inno Setup Windows per pengguna/uninstaller. (3) tes path/backend, suite regresi, smoke bundle, pengecekan isi/hash, dan workflow build native Linux/Windows.

Tidak mengubah layout, widget, objectName, signal/slot, handler editor/koleksi/A-B/perangkat, konfirmasi atau algoritme audio. Perubahan lokasi data hanya diperlukan untuk paket terpasang; data pengguna tidak dimasukkan ke paket dan tidak dimigrasikan otomatis. Build dependencies PyInstaller, appimagetool dan Inno Setup hanya alat packaging, bukan runtime baru. Python/Qt/MIDI dibundel, sehingga ukuran paket lebih besar. Tidak menulis/mengunggah repo atau menjalankan workflow eksternal tanpa repo dan otorisasi yang jelas.

Batas lingkungan: host Linux x86_64/glibc 2.44, bukan Windows. PyInstaller bukan cross-compiler. Artifact Linux lokal diuji untuk host ini; build generik perlu baseline distro lebih tua. Windows .exe harus dibangun/diverifikasi di runner Windows. Docker terpasang tetapi socket belum dapat diakses. Git metadata di workspace tidak dikenali. Metadata dan format bank/preset/IR tetap.

Audit portabilitas tambahan: collection.atomic_json/durable_directory dan ir_writer.save_backup memakai O_DIRECTORY/fsync khusus POSIX. Untuk Windows gunakan publikasi file sementara yang sudah di-fsync melalui MoveFileExW WRITE_THROUGH (tanpa replace untuk cadangan eksklusif); kegagalan tetap dilempar sebelum operasi tulis pedal. Jalur POSIX tetap, format/payload/urutan backup-before-erase tidak berubah. Ini diperlukan agar installer Windows berfungsi dan tidak sekadar membuka UI. Rujukan: https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw .

Repo GitHub kini tersedia pada main (`9da7ebe`), izin akses telah dibaca. Rencana memakai branch packaging terpisah dan push-trigger Actions, tanpa mengubah main; hasil build diambil sebagai artifact, bukan menerbitkan release otomatis.

Dependency release memakai komponen PySide6_Essentials dan PySide6_Addons (tetap namespace PySide6) agar metapackage PySide6 6.12 tidak menarik WebEngine/PDF yang tidak digunakan. Semua versi dipatok. Ini mengurangi dependency build tanpa menghilangkan QtWidgets/QtMultimedia.

Build native pertama: Linux perlu utilitas file; Windows mengungkap default encoding cp1252 dalam tes pembacaan source dan perbedaan minimum layout. Source test dibaca UTF-8; basis style widget ditetapkan Fusion agar ukuran kontrol konsisten lintas OS, tanpa memaksa QFileDialog non-native. Tes layout tetap ketat dan mendapat konteks page/ukuran; diagnostik layout ditambahkan pada workflow saat gagal.

Smoke frozen Linux pada Python 3.10 menemukan abort refcount None dalam binding Qt; host Python 3.14 tidak terkena. Baseline build dinaikkan ke Python 3.12 pada Debian 12 (glibc 2.36), sama dengan target Python Windows. Dokumentasi syarat glibc dan Python disesuaikan; tidak menyatakan kompatibilitas Ubuntu 22.04. Ditambah client library PipeWire pada builder untuk QtMultimedia.

Diagnostik Windows menetapkan sisa overflow pada Koleksi: strip Buat preset/Buat baru/Impor file memberi minimum lebar panel kiri 566 px, sehingga total halaman 972 px pada viewport 896 px. Tiga tombol strip diizinkan berbagi lebar panel; tes baru memeriksa seluruh halaman dan label tombol muat pada 1000×680. Tidak melonggarkan batas ukuran atau menyembunyikan aksi. Style Fusion dipertahankan untuk basis metrik widget yang konsisten; native file picker tetap diizinkan.

Diagnostik lanjutan menemukan penyebab metrik ekstrem pada runner Windows: platform offscreen tidak menemukan font sistem, sehingga setiap karakter memakai lebar dummy 14 px. Workflow kini menyediakan direktori font Windows melalui QT_QPA_FONTDIR. StudioUI memilih font yang benar-benar tersedia (Inter, Noto Sans, Segoe UI, lalu font aplikasi). Pemeriksaan layout 1000×680 pada keempat halaman kini lulus di Windows. Tidak membundel font tambahan atau mengubah skala tipografi.

Verifikasi akhir lokal: 205 tes regresi lulus (208,452 detik), build AppImage Debian 12/Python 3.12 lulus, checksum kedua paket Linux cocok. Executable AppImage aktual, salinan yang terpasang, integrasi menu, dan uninstall diuji dalam XDG sementara; data Koleksi tetap ada setelah uninstall. Semua pemeriksaan bundle memuat QtMultimedia, API MIDI target, empat halaman, factory IR 32768 byte, serta round-trip Koleksi.

Per halaman: Editor, Bandingkan IR, dan Perangkat mempertahankan widget/handler serta alur lama; Koleksi hanya mendapat pembagian lebar strip tombol agar tetap muat. Penyesuaian lintas halaman terbatas pada basis style/font. MIDI hanya memilih backend OS; protokol, parsing, format bank/preset/IR, algoritme audio, kondisi aktif/nonaktif dan konfirmasi tetap. Lokasi data terpasang dipisahkan dari program, dan penulisan atomik Windows memakai API sistem dengan kegagalan yang tetap diteruskan.

Checklist simulasi: navigasi empat halaman, ukuran minimum, kontrol slider/preset, impor/ekspor, state offline/sibuk/gagal, meter, A/B, konfirmasi reset, fokus/shortcut dan native file picker dicakup suite UI/regresi. Pemeriksaan koneksi USB, audio langsung, baca/tulis slot, pengiriman IR, Loopback serta cadangan/pemulihan pada pedal fisik belum dilakukan; hasil simulasi tidak dianggap pengujian perangkat.

GitHub Actions run 44749106353 pada commit ff491cf berhasil untuk Linux dan Windows. Windows menjalankan 205 tes dalam 155,773 detik (satu tes integrasi Linux dilewati sesuai platform), membangun Setup.exe, menjalankan self-test executable bundle dan executable hasil instalasi, lalu uninstall dengan exit code sukses. Paket tersedia sebagai artifact Actions; source tetap di branch codex/installers-linux-windows dan belum digabung ke main. Laporan JSON menyatakan physical_pedal_tested=false. Pemeriksaan compileall dan git diff --check lokal juga lulus; tidak ada konfigurasi lint terpisah di repo.

Helper runtime: app_paths.py, bundle_support.py dan windows_io.py. Pemakai helper lokasi data/backend: collection.py, device_ui.py, gui.py, ir_writer.py, midi.py, suite_gui.py dan transfers.py. Perubahan tambahan terbatas pada font/style/strip Koleksi di studio_ui.py, metadata versi, daftar source package, ignore files dan tes regresi.
