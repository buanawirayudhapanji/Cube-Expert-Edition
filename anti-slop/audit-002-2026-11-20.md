# Audit tipografi dan spacing sebelum edit

Permintaan pengguna: satu standar hirarki teks dan padding/margin untuk semua UI. Mode antislop after tetap; perubahan berikut secara eksplisit diminta pengguna. Arah visual dan susunan halaman dipertahankan, tanpa aset/dependensi baru.

Acuan: Material Design type roles (https://github.com/material-components/material-components-android/blob/master/docs/theming/Typography.md) dan spacing 8/4 (https://m2.material.io/design/layout/spacing-methods.html). Adaptasi Qt desktop: ukuran dalam logical pixel, bukan unit Android sp/dp. Judul halaman 28/600, judul panel 16/600, label kontrol 14/500, isi 14/400, keterangan 12/400, label kecil 12/500. Font sans aplikasi dipilih sekali; meter/log tetap monospace.

1. HIGH R-06/R-35: QSS memakai ukuran/weight ad hoc, eyebrow 10 px dan delegate metadata 11 px. Status koneksi mengambil peran cardTitle dan judul A/B punya override lokal. Satukan token tipografi dan bedakan title/field/body/caption tanpa mengubah data atau isi nama pengguna.
2. HIGH R-03/C-4: padding compact card 10/4 dan gap hasil pembagian otomatis membuat teks menempel tepi. Sediakan dua density yang konsisten: normal pad16/gap12, compact pad12/gap8; pasangan label-hint gap4, jarak field8, panel16, section24. Kontrol compact boleh lebih rendah, tetapi ukuran teks tidak dikecilkan.
3. MEDIUM R-31/C-1: default spacing Qt bercampur angka 5/6/9/10/14/18/22/26. Standarkan default Qt, layout/dialog, dan inset item delegate pada grid4; pisahkan kelompok koneksi, output, loopback dan bantuan agar hubungan antar elemen jelas.

Tahap: (1) token dan QSS, (2) pemetaan peran teks serta layout empat halaman/dialog/delegate, (3) render normal/compact, semua tab pada 1000×680, tema gelap/terang, dan suite regresi. Git tidak dikenali di lingkungan ini, jadi gunakan langkah teruji.

Peta sambungan diperiksa ulang: StudioUI menggunakan widget milik SuiteWindow (`ports`, `outputs`, connect/status), navigasi `navigate/sync`, preset_selector/preset_buttons, effect_controls/effect_switches dan sinkronisasi slider-spin. AudioMeter tetap refresh_inputs/toggle_monitor/reset_peak. LibraryPanel tetap render/selection_changed, import/export/capture/send_selected/stage_selected; comparison tetap choose_ab/set_ab/play_ab, same_distance/same_peak. Device tetap BackupPanel/MidiLogPanel, Loopback dan reveal/confirm reset. Batas send_query/poll/device_ready/update_controls/start_transfer tidak disentuh. Tidak memindahkan kepemilikan widget fungsional; perubahan hanya font, peran presentasi, layout dan ukuran.
